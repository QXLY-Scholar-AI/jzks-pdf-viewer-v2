# jzks-pdf-viewer 第二版

按五步精读论文，生成可复制正文、原文高亮、中文批注与本地阅读网页。

## 安装和调用
将压缩包内jzks-pdf-viewer文件夹放入Codex的skills目录，提供PDF并输入：

> 请调用jzks-pdf-viewer，完成这篇论文的文献精读。

生成依赖Python 3.10及以上与PyMuPDF（python -m pip install pymupdf）。AI在Codex中阅读写作，脚本生成阅读器；网页不需要模型密钥。

## 精读要求
保留问题、方法、结果、证据与结论、局限五部分；补充全局地图、可检验假设、作者声称的缺口、按研究类型检查方法、结论逐项对照及有区分检验的替代解释。已读过作者解释时记为证据复核。关键判断带真实原文位置，作者报告、AI解读和我的纠正分开。

## 阅读功能
- 正文整篇或按节复制、下载Markdown，出处与原文双向定位。
- 收起精读进入原文专注模式；筛选方法、结果、疑问、个人笔记；显示或隐藏高亮。
- 保存页码、章节、缩放、筛选和阅读位置。
- 框选勾画、笔记编辑删除、在AI批注旁补充个人纠正。
- JSON笔记导入导出，同论文身份核对与去重。
- 网页下载PDF时合并AI批注、个人框选及纠正；边栏靠近证据并自动避让。脚本最初生成的annotated-paper.pdf仅含AI批注。

## 第三方组件
离线PDF导出使用pdf-lib，MIT许可随Skill放在assets/vendor/pdf-lib-LICENSE.md。阅读器不依赖外部CDN。
