# 精读过程与质量要求

每次精读都读取本文件。界面保留五部分，阅读过程补足全局地图、可检验问题、知识缺口、方法适配、证据结论对照和替代解释。

## 阅读顺序
1. 核实论文版本、正文范围；记录补充材料、数据、代码是已查阅、仅见链接还是未获得。
2. 浏览结构、方法和图表，定位研究类型、对象、主要比较与关键图表。优先阅读方法与结果，把数据直接支持的结论记入`evidence-conclusions.md`，再读完引言、讨论和结论并逐项对照；记录实际接触过哪些章节。
3. 已经看过摘要结论、讨论或既有精读时，执行“证据复核”，不能称为盲读。同一上下文分阶段提示并不能消除已见信息。只有确实隔离作者解释时才称结果盲读。
4. 默认连续完成；用户要求参与或关键材料不能辨认时才停，不默认增加人工关卡、多代理或外围研究。

## 五部分的要求

### 1 问题与全局地图
说明研究类型、对象、输入输出、比较和2—3个关键图表。区分作者明确的问题、AI还原的问题与可检验预测。预测说明：若解释成立应看到什么，什么结果会削弱它。

还原作者声称的知识缺口：已有方法做到什么、剩下什么、本文新增什么。仅凭本文不能断言是领域真实空白。需要判断首创性或外部支持时，再检索相称范围的原始文献并注明范围。

### 2 方法是否回答了问题
先解释关键方法原理及作用，再按研究类型检查影响结论的环节，不套全部清单。

| 研究类型 | 重点 |
|---|---|
| 计算、机器学习、预测 | 样本实体与时间划分，标签及泄漏，强基线与调参预算，重复与不确定性，消融，外部验证，数据代码和环境 |
| 观察、因果推断 | 样本选择，测量时序，混杂，识别假设，缺失数据，稳健性及外推 |
| 随机与干预试验 | 分配，对照，盲法，实验单位，主要结局，失访和分析集 |
| 基础与动物实验 | 生物学/技术重复，阴阳性对照，批次，随机化，原始图像 |
| 系统综述 | 检索日期与范围，纳排、筛选、偏倚、样本重叠、异质性 |
| 理论、定性及其他 | 按设计检查假设与推导边界、反例，或抽样、编码及解释可追溯性 |

问题区分“未报告”“设计风险”“分析风险”“无法判断”，说明具体影响；缺少报告不等于方法错误。未执行代码或实验不能写已复现。使用正式报告规范/偏倚工具时核对适用版本，不将轻量检查冒充完成标准化评估。

### 3 结果先还原，再解释
核心结果带比较对象、指标含义与方向、数值及单位、条件和已报告的不确定性。解释关键图表在回答什么。不能把未报告区间写成没有效果，不能从低清曲线估精确值，区分相关与因果。

### 4 对照两套结论
主要结论交代：作者主张→直接证据→可支持的表述→差异。差异可为一致、作者更强、更弱、范围不同或证据不足。数值冲突并列保留。指出最强证据与最薄弱连接；同时解释论文贡献，避免只有挑错。

### 5 替代解释与使用决定
保留1—3条与论文直接相关的替代解释，有依据才增加。每条包含机制、预期现象、区分检验、当前证据是否排除。可能性不写成已发生，不编造概率或利益关系。

最后说明可学习的思路、适合怎样引用及最关键的待补材料。作者未来工作、AI检验建议和用户纠正分别保留。

## 交付检查
问题、方法、证据、结论是否连贯；是否讲清贡献和原理；关键数字是否回到原表；引句是否真正支持判断；替代解释是否给出检验；已接触作者结论是否如实记录。
